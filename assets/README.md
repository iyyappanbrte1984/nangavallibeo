# Asset Files for TN Independence Day Certificate Generator

You can replace these asset files with your original high-resolution PNG or JPEG images when running locally or on GitHub.

## Files:
1. `tn_emblem.png` - Tamil Nadu Government Seal / Emblem logo
2. `signature_supervisor.png` - Signature image for Supervisor (மேற்பார்வையாளர்)
3. `signature_beo1.png` - Signature image for Block Educational Officer 1 (வட்டாரக் கல்வி அலுவலர் 1)
4. `signature_beo2.png` - Signature image for Block Educational Officer 2 (வட்டாரக் கல்வி அலுவலர் 2)

## Instructions:
Simply drop your transparent PNG images into this `public/assets/` folder with the exact filenames listed above.
The application is pre-configured with auto-fit containers (`object-contain`, responsive scaling) so your uploaded images will display automatically in perfect alignment on the certificate!
